How it works

Three steps, once.

Add the MCP server

Point your agent at skym-flow. Claude Code picks up the chart tools automatically.

claude mcp add skym-flow -- npx -y skym-flow

Pair this account

The first chart tool prints a code. Enter it in Settings and the agent syncs here from then on.

Watch it build

Ask your agent to work as usual. The chart fills in as it goes — open it from My Charts.
