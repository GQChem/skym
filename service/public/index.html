Connect once. Keep working normally.

skym is an MCP server your agent calls as it works.

Add the MCP server

Run the published package directly from npm. Then copy CLAUDE.md.example into your project's CLAUDE.md — the tools stay idle unless Claude is told to call them.

claude mcp add skym-flow -- npx --yes skym-flow@latest

Pair this account

The first chart tool prints a code. Enter it in Settings and the agent syncs here from then on.

Watch it build
