# Security

Please do not disclose vulnerabilities in a public issue. Use GitHub's
**Security → Report a vulnerability** flow for this repository so maintainers
can investigate and coordinate a fix privately.

Include the affected version or deployment, reproduction steps, impact, and any
suggested mitigation. Do not access other users' data, disrupt the hosted
service, or retain data encountered while validating a report.

The latest release is the supported version. Security fixes will be documented
in release notes after affected deployments and packages have been updated.
